# USP15 R10 rank01 真实结合路径模拟

本任务只针对 `USP15_R10_rank01`。它不把已有的 bound-state 100 ns 轨迹反向解释为结合过程，而是从已审计的 ff19SB/OPC 全溶剂复合物体系出发，将 binder 链 A 的初始坐标平移到距 USP15 DUSP 链 B 质心约 35 Å 的分离态，再进行无约束最小化、1 ns NPT 预平衡和 3 条独立的 100 ns NPT 生产轨迹。

固定设置：OpenMM 8.5.2、AMBER ff19SB、OPC 显式水、300 K、1 bar、2 fs。最小化、预平衡和生产阶段均不添加 binder–target 距离或位置约束。轨迹使用蛋白原子 10 ps 间隔保存，后处理计算质心距离、最小重原子距离、Cα 接触、6 个热点的接触占有率，并从轨迹帧生成旋转式结合路径动画。

这是一组无偏动力学结合尝试：如果 100 ns 内没有从分离态形成稳定界面，报告应明确写成“未观察到结合事件”，不能用几何插值替代。轨迹指标和动画也不能直接给出 KD、kon/koff 或绝对结合自由能。
