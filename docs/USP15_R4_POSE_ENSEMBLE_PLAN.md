# USP15 R4 6DJ9 晶体构象集计划

## 目的

R1–R3 在固定 USP15 DUSP 靶点和既定 AF2 门控下未收敛。R4 不改变靶点、
热点、序列门控或 AF2 测试，而是利用 6DJ9 不对称单元内四个独立
DUSP–UbV 晶体拷贝，对实验界面几何的构象差异进行一次有界采样。

本阶段仍属于计算候选发现，不代表生化抑制、细胞活性或实验选择性。

## 输入与构象

- 完整靶点：3T9L 链 A 6–134。
- 实验复合物：6DJ9 不对称单元。
- 可直接解析的四组目标–binder 链：
  - A–K
  - B–L
  - C–J
  - D–H
- 每组使用 DUSP 的 25–70 位 CA 原子与完整 3T9L 靶点对应残基做刚体拟合。
- Binder 统一为链 A 1–76，完整 USP15 靶点统一为链 B 6–134。
- 以界面外法向的有界起点做确定性三维跨链排斥位移搜索，并选择满足
  条件的最小刚体平移：
  - 小于 2 Å 的跨链接触原子对为 0；
  - 5 Å 内仍覆盖至少 4 个既定热点。

不使用需要晶体对称操作才能恢复界面的 E/F 拷贝，以免引入未经验证的
晶胞变换。

## 序列设计

- 固定 6DJ9 晶体界面位置：
  `4,6,7,8,9,44,46,48,49,50,51,72,73,74,75`。
- 其余 61 个 binder 位置由 ProteinMPNN 设计。
- 每个构象 3 条序列，共 12 条。
- temperature `0.1`，omit `C`，无氨基酸 bias。
- 每条序列必须：
  - 长度为 76 aa；
  - 不含 Cys；
  - 固定的 15 个界面残基与输入晶体构象一致；
  - 在同一构象内互不重复。

## AF2 正向门控

只运行 `af2_model_1_multimer_tt_3rec`，门控保持不变：

- iPAE ≤ 10；
- target-aligned binder RMSD ≤ 2 Å；
- binder pLDDT ≥ 80。

GPU 阶段继续在单张 V100 上串行运行，不使用 PyRosetta。

## 决策规则

- 至少 3 条序列同时通过全部正向门控：立即进入 USP4/USP11 选择性反筛。
- 1–2 条通过：只对通过构象做一次有界重复，不扩展其他分布。
- 0 条通过：停止本构象集分支，不按单项指标挑选，也不放宽阈值。
- 只有同时通过 USP15 正向门控和原计划 USP4/USP11 反筛的去冗余序列，
  才能计为最终计算候选。

## 可审计输出

- 四个标准化输入复合物 PDB；
- 输入构象拟合 RMSD、去碰撞位移和热点接触诊断 JSON；
- ProteinMPNN 序列一致性检查 JSON；
- 12 条 AF2 记录及 CSV、FASTA、汇总 JSON；
- 每条失败序列的固定门控结果。
